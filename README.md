## Featured Projects

### 🔍 [DefectLens AI](https://github.com/moise744/defectlens-ai)
**Industrial Visual Inspection & Anomaly Detection**

Detects manufacturing defects (scratches, cracks, dents, surface irregularities) in industrial products using anomaly detection and image classification on the MVTec AD dataset. Includes defect region segmentation, visual heatmaps, and an interactive inspection dashboard.

`PyTorch` · `Anomaly Detection` · `Image Classification` · `Segmentation` · `Streamlit`

---

### 📊 [LineCount AI](https://github.com/moise744/linecount-ai)
**Real-Time Object Detection, Tracking & Counting**

Real-time system that detects, tracks, and counts products on manufacturing conveyor belts. Uses YOLOv8 for detection, ByteTrack for persistent object tracking, and virtual line-crossing logic for accurate counting with anti-double-count protection.

`YOLOv8` · `ByteTrack` · `Object Tracking` · `OpenCV` · `FastAPI`

---

### 🛡️ [SurfaceGuard](https://github.com/moise744/surfaceguard)
**Industrial Defect Segmentation**

Pixel-level defect segmentation system that identifies the exact shape and location of surface defects in industrial images. Implements U-Net and DeepLabV3+ architectures with detailed mask comparison and failure-case analysis.

`U-Net` · `DeepLabV3+` · `Semantic Segmentation` · `Dice Loss` · `PyTorch`

---

### 🌿 [AgroScan AI](https://github.com/moise744/agroscan-ai)
**Agricultural Disease Detection & Classification**

Classifies plant diseases from leaf images using the PlantVillage dataset (38 classes). Includes Grad-CAM visual explanations showing which leaf regions influenced the model's prediction, with a web interface for real-time inference.

`Image Classification` · `Grad-CAM` · `Transfer Learning` · `ResNet` · `Streamlit`

---

### ⚙️ [PartVerify AI](https://github.com/moise744/partverify-ai)
**Manufacturing Assembly Verification**

Visual inspection system that verifies whether manufactured components are correctly assembled. Detects individual parts, checks spatial relationships against expected configurations, and generates pass/fail inspection reports.

`Object Detection` · `Rule Engine` · `FastAPI` · `Inspection Reports` · `YOLO`
